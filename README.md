## 🚀 Quick Start

To run this project locally, make sure you navigate into the application directory first before running any Flutter commands:

```bash
# 1. Clone this repository
git clone https://github.com/Rosh-pvr/GRS-AC-CIRCUIT-CALCULATOR.git

# 2. Navigate into the Flutter app directory
cd GRS-AC-CIRCUIT-CALCULATOR/GRS_app

# 3. Install dependencies
flutter pub get

# 4. Run the app
flutter run
```
